# Komentář k vyhlášce č. 121/2019 Sb., o materiálním vybavení a standardech výkonu funkce insolvenčního správce

Otevřený komentář k vyhlášce o materiálním vybavení a standardech výkonu funkce insolvenčního správce — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; sídlo a provozovna, úřední hodiny, odborná péče, přezkum pohledávek, soupis a zpeněžení majetkové podstaty, dohled nad dlužníkem, splátky a spis.

Konsolidované znění: dokument e-Sbírky `SB-2019-00121_2026-01-01`.
